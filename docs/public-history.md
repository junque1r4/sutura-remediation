# Public source snapshot

This public distribution starts with a reviewed source snapshot and a new Git
history. Earlier commits are intentionally not included, so private development
material and historical metadata are not published accidentally.

A fresh repository does not demonstrate a long-standing public contribution
history. No commits or dates have been fabricated to imply otherwise.

The source includes contributions by more than one author. The MIT license and
its copyright notice are preserved, and [AUTHORS.md](../AUTHORS.md) retains the
known author credits from the source history without publishing private contact
details. The maintainer is not claiming to have authored every contribution.

The interface previews use synthetic data. They are illustrations, not customer
screenshots, security findings, benchmark results, or production evidence.

Review any project-submission program's ownership, contribution-history, and
eligibility requirements separately before submitting this repository.
